API pública

Brazil Locations

Países, regiões, UFs e municípios brasileiros com código IBGE. Leitura, sem autenticação, sem chave.

Endpoints

MétodoRotaO que faz
GET/v1/locations/states27 UFs com região
GET/v1/locations/states/{uf}/citiesMunicípios da UF
GET/v1/locations/cities?search=Busca por nome (ignora acento)
GET/v1/locations/cities/{code}Município pelo código IBGE
GET/healthEstado do serviço

Exemplos

curl http://127.0.0.1:8130/v1/locations/states

curl "http://127.0.0.1:8130/v1/locations/states/MT/cities?limit=5"

curl "http://127.0.0.1:8130/v1/locations/cities?search=floresta&uf=RO"

curl http://127.0.0.1:8130/v1/locations/cities/1100015

Resposta

{
  "uf": "MT",
  "count": 142,
  "data": [
    { "id": 5101, "ibge_code": "5100102", "name": "Acorizal", "uf": "MT" }
  ]
}

Para agentes de IA

Existe uma versão enxuta, sem HTML: /llms.txt. E a especificação completa em /openapi.json.

Cache

Todas as respostas trazem X-Cache (HIT, MISS ou BYPASS) e X-Cache-Driver. O dado muda uma vez por ano, então o cache é agressivo: 24h para listas, 5 min para busca.

Regras

  • ibge_code é a chave estável — id é interno.
  • Busca é por prefixo, sem acento e sem diferenciar caixa.
  • Cache público de 1 dia; o dado muda uma vez por ano.
  • Erros sempre em JSON com o campo error.
